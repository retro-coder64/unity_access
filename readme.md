# Unity access 
## what is unity access 
unity access is a plugin for the unity 6.3 lts editor that allows screen reader users to work the previously inaccessible editor. 
It exposes common editor functions to NVDA through use of a custom wrapper and the Unity Editor API. 
It has been vibe coded with openai codex. 
the project is designed to provide VI users with a plug and play experience. 
All the code in the repo is free and opensorce.
## requirements 
to use this plugin you will need: 
- unity 6.3 lts 
- NVDA screen reader 
## installation 
to install the plugin clone the repo into a folder and then extract the Editor folder. 
Then, place it under assets in the unity project you are working in. 
Load the unity project and allow it to recompile the new scripts. 
## starting the plugin 
to start the plugin navigate to the file menu in the unity editor by pressing alt f. 
then press esc and use the arrow keys to navigate to unity access. 
enter the submenu and press enter on start.
